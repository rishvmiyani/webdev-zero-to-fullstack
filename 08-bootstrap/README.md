- ✅ Utility-first workflow

### 2️⃣ Utilities Cheatsheet – `02-utilities-cheatsheet`
Master the most-used Bootstrap utility classes.

**Includes:**
- ✅ Spacing → `m-3`, `p-4`
- ✅ Colors → `bg-primary`, `text-success`
- ✅ Display → `d-flex`, `d-none`
- ✅ Position → `position-sticky`
- ✅ Responsive helpers → `d-md-none`
